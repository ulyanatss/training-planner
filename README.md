# Training Planner

**Автор:** Ульяна Цыпышева

Простое GUI-приложение на Python для планирования тренировок. Позволяет добавлять записи (дата, тип, длительность), фильтровать их и сохранять данные в формате JSON.

## Функциональность
- Добавление тренировок с валидацией ввода.
- Фильтрация по типу и/или дате.
- Сохранение и загрузка данных в/из файла JSON.
- Удобный табличный просмотр.

## Запуск
1. Убедитесь, что установлен Python 3.6+.
2. Клонируйте репозиторий или скопируйте файлы.
3. Запустите `training_planner.py`:

```bash
python training_planner.py
```
